# Come aggiungere un materiale

1. Carica il file .html della lezione nella cartella della materia e della classe,
   per esempio `geografia/terza/clima.html`
   (su GitHub: Add file → Upload files; per creare una cartella nuova scrivi
   il percorso nel nome del file con Add file → Create new file, es. `storia/prima/nome.html`).
2. Apri `materiali.js`, clicca sulla matita, copia un blocco `{ ... }`,
   incollalo sotto l'ultimo (con una virgola in mezzo) e cambia i dati.
3. Commit changes. Dopo un minuto la lezione compare nella pagina della materia
   e tra gli "Aggiunti di recente" della home.

Non serve toccare `index.html`, le pagine delle materie o la cartella `assets`.
